CAPACITÉS

    
Ce que fait la passerelle

    

      

        
        
Détection multicatégorie

        
E-mails, téléphones, cartes (contrôle de Luhn), adresses IP, IBAN et comptes bancaires, mots de passe, clés et JWT, adresses postales, dates de naissance, pièces d'identité, dictionnaire personnalisé et noms en contexte.

      

      

        
        
Jetons réversibles par session

        
Une même valeur reçoit toujours le même jeton dans une session, pour garder le contexte cohérent. Les correspondances sont chiffrées avec Fernet.

      

      

        
        
Compatible OpenAI

        
Pointez votre client existant sur /v1 : chat completions, y compris le streaming SSE démasqué à la volée.

      

      

        
        
Journal sans valeur brute

        
SQLite local chiffré, audit limité aux catégories, comptages et empreintes. Rétention et purge automatiques configurables.

      

      

        
        
Mode strict

        
Les formes de contenu non prises en charge et les pannes amont sont refusées plutôt que risquées en clair. Le diagnostic est audité.

      

      

        
        
Multilingue

        
Indices de détection en anglais, français, malgache, allemand et espagnol, sur une base de règles locale et vérifiable.

      

    

    
La détection par règles est une base fiable, pas une garantie de conformité. Ajoutez un détecteur NER local (spaCy/Presidio) via Detector pour un rappel plus élevé.

  







  

    
INTÉGRATION

    
Une ligne de configuration, aucun code à changer

    

      

        

          
          
          
          
          
        

        
Python · client OpenAI


from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8787/v1",
    api_key="local-dev-key",
)

client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user",
               "content": "Écris un mail à ana@example.com"}],
)

        
Le même client OpenAI, seul le modèle change : VEILFORGE_UPSTREAM_URL doit pointer vers un amont compatible (par ex. OpenRouter) qui sert ces modèles.
